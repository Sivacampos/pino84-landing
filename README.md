# Pino 84 Apartments — Landing page

Landing page del edificio **Pino 84 Apartments** (Calle Pino, 84 · Vigo): 6 apartamentos turísticos, estudios y de un dormitorio.

## Estructura

```
index.html      → página completa (HTML + CSS inline, sin dependencias de build)
images/         → logo, ilustración del hero y fotos de los apartamentos
```

## Ver en local

Abre `index.html` en el navegador, o sirve la carpeta:

```bash
python3 -m http.server 8000
```

## Publicar con GitHub Pages

Settings → Pages → Source: *Deploy from a branch* → `main` / `(root)`.
